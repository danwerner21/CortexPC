Tile Studio Converter v0.1
==========================

This small utility authored by Retroclouds is part of the SPECTRA library.

Tile Studio Converter is used for generating 16x16 sprite pattern data  
from Tile Studio (http://tilestudio.sourceforge.net/).

Unfortunatly this did not make it in SPECTRA reference manual but will be included
in the next version.

This utility is still an early prototype that only reliably works in Firefox 2.x and 3.x
Currently there is still a visualisation issue with Internet Explorer that will be sorted
out in the next version. 


Following files included:

tsdc.html               
   The converter itself. 
   Standalone web-page with the converter written in Javascript.

TI994A_sprites_16x16.tsd 
   Plug-in for Tile Studio.
   It is a text-file you should copy in the Tile Studio directory.
   Is required for generating code from Tile Studio.

example/time_pilot - parachute tiles.tsp 
   Tile Studio Project.
   Parachutes from screenshots taken from arcade version of Time Pilot (MAME)
                                
example/time_pilot_parachutes.txt 
   Code generated by Tile Studio using TI994A_sprites_16x16.tsd
   When the code is generated it will have file name sprites_16x16.raw
   You can then rename it to e.g. time_pilot_parachutes.txt


To do the conversion to actual sprite pattern data:

1. Open time_pilot_parachutes.txt in a text editor (for example notepad)
2. Open tsdc.html in Firefox
3. Use copy-and-paste to copy the line containing @SPRITE_16X16@ into the
   text field
4. Press "convert" button to generate sprite pattern data.
   You can then set a color for each layer and press "convert" again.
